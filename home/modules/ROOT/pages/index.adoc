== Install

kwenza needs JDK 21 or newer. Until the first release is packaged, build it from source:

[source,bash]
----
git clone https://github.com/kwenza-build/kwenza.git && cd kwenza
./bootstrap.sh && bin/kwenza package
export PATH="$PWD/bin:$PATH"
----

xref:docs::getting-started.adoc#_installing_kwenza[More on installing]

[.cards]
* [.card-title.declarative]#xref:docs::manifest-reference.adoc[Declarative]#
The manifest is data. It never runs, so reading it tells you everything.
* [.card-title.interoperable]#xref:docs::architecture.adoc[Interoperable]#
Maven Central, `~/.m2`, `src/main/java`. Your IDE and cache keep working.
* [.card-title.reproducible]#xref:docs::manifest-reference.adoc#_kwenza_lock[Reproducible]#
`kwenza.lock` wins by default. No network unless your dependencies changed.
* [.card-title.transparent]#xref:docs::cli-reference.adoc#output[Transparent]#
Every command prints what it actually ran.
